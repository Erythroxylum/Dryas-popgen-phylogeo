# Dryas population genetics and phylogeography

This repository compares 28 relatively uniform reference populations with 28
geographically coherent admixed populations in the cleaned pan-*Dryas* GBS
dataset.

Raw sequence identifiers are never renamed. `sampleID` is the canonical key in
the metadata, while `phyloID` is used only for display. If an input file uses an
older identifier, `scripts/01_validate_metadata.R` resolves it through `s384`
or `oldfilename` and writes an explicit alias table.

## Inputs

Place these files in `data/`:

- `Dryas_sampledata_popgen.csv`
- `s384_batchclean_ab25_locusFDR05_mac4_dp15-150_miss10.sorted.vcf.gz`
- its `.tbi` index
- `s384.loci.gz` for the later sequence-level nucleotide-diversity analysis

The cleaned VCF contains 95,479 SNPs after batch-associated loci were removed,
genotypes were masked by depth and allele balance, and MAC was recalculated.
The population analysis uses only samples assigned in both `pop_gen` and
`pop_gen_population`.

## Environment

```bash
conda env create -f environment.yml
conda activate dryas-popgen
```

## Workflow

After checking the paths below, steps 1-5 can also be run together:

```bash
NBOOT=1000 NCORES=4 bash scripts/00_run_core.sh
```

### 1. Validate identifiers and create population maps

```bash
Rscript scripts/01_validate_metadata.R \
  data/Dryas_sampledata_popgen.csv \
  data/s384_batchclean_ab25_locusFDR05_mac4_dp15-150_miss10.sorted.vcf.gz \
  results/metadata
```

This writes the VCF-to-metadata crosswalk, all aliases, the 215 selected raw
identifiers, a dartR metadata file, and population counts. The script stops on
ambiguous or missing identifier mappings.

### 2. Subset the VCF and retain one SNP per ipyrad locus

```bash
bash scripts/02_subset_popgen_vcf.sh \
  data/s384_batchclean_ab25_locusFDR05_mac4_dp15-150_miss10.sorted.vcf.gz \
  results/metadata/assigned_raw_ids.txt \
  results/vcf
```

The full selected-sample VCF is used for individual SNP heterozygosity. The
one-SNP-per-locus VCF chooses the SNP with the highest called-sample count in
each `locN` ipyrad locus and is used for population summaries and F-statistics.

### 3. Population diversity

```bash
NBOOT=1000 Rscript scripts/03_population_diversity.R \
  results/vcf/s215_popgen_one_snp_per_locus.vcf.gz \
  results/metadata/sample_to_population.tsv \
  results/diversity
```

This uses `dartR` to import the VCF and `hierfstat` to calculate observed
heterozygosity, within-population gene diversity, FIS, and allelic richness
rarefied to six gene copies. Confidence intervals resample the independent
ipyrad-locus representatives.

### 4. Individual SNP heterozygosity

```bash
Rscript scripts/04_individual_heterozygosity.R \
  results/vcf/s215_popgen_all_snps.vcf.gz \
  results/metadata/sample_to_population.tsv \
  results/diversity/individual_snp_heterozygosity.tsv
```

### 5. Pairwise differentiation

```bash
NBOOT=1000 NCORES=4 Rscript scripts/05_pairwise_fst.R \
  results/vcf/s215_popgen_one_snp_per_locus.vcf.gz \
  results/metadata/sample_to_population.tsv \
  results/fst
```

This calculates pairwise Weir-Cockerham FST and 95% locus-bootstrap intervals
with the parallel StAMPP implementation wrapped by `dartR`. The full matrix is supplementary output; focal admixed-to-
reference comparisons can be selected after reviewing the matrix.

### 6. Filtered sequence-level nucleotide diversity

The `.loci` parser uses invariant sequence positions as the denominator but
allows differences only at variants retained in the batch-cleaned VCF. Use the
original cleaned VCF (genomic sorting is not required) and the 637-locus
exclusion list generated by the batch-QC repository.

```bash
python scripts/06_filtered_sequence_pi.py \
  data/s384.loci.gz \
  data/s384_batchclean_ab25_locusFDR05_mac4_dp15-150_miss10.sorted.vcf.gz \
  results/metadata/sample_to_population.tsv \
  results/metadata/identifier_aliases.tsv \
  results/diversity/filtered_sequence \
  --exclude-loci data/exclude_loci_strict_FDR05.txt

NBOOT=1000 Rscript scripts/07_bootstrap_sequence_pi.R \
  results/diversity/filtered_sequence_per_locus_pi.tsv.gz \
  results/diversity/filtered_sequence_pi_bootstrap_ci.tsv
```

### 7. Pairwise sequence divergence

Calculate absolute sequence divergence (dXY) from the same callable positions,
retained variants, sample assignments, and excluded batch-associated loci used
for sequence-level nucleotide diversity. The compressed NPZ is an intermediate
locus-by-population-pair object and is ignored by Git.

```bash
python scripts/08_filtered_sequence_dxy.py \
  data/s384.loci.gz \
  data/s384_batchclean_ab25_locusFDR05_mac4_dp15-150_miss10.sorted.vcf.gz \
  results/metadata/sample_to_population.tsv \
  results/metadata/identifier_aliases.tsv \
  results/divergence/filtered_sequence_pairwise_dxy \
  --exclude-loci data/exclude_loci_strict_FDR05.txt

NBOOT=1000 python scripts/09_bootstrap_sequence_dxy.py \
  results/divergence/filtered_sequence_pairwise_dxy_per_locus.npz \
  results/divergence/filtered_sequence_pairwise_dxy
```

`--position-base 0` is the ipyrad default assumed by the script. The script
fails if any selected sample cannot be resolved through `sampleID`, `s384`, or
`oldfilename`.

### 8. Diversity of uniform populations within evolutionary lineages

The revised `spID` column assigns each sample to an evolutionary lineage. This
analysis retains only `pop_gen == uniform` populations. It recalculates private
allelic richness for each geographic population relative only to the other
uniform populations in its lineage, then combines those estimates with the
existing population-level pi, observed heterozygosity, and expected
heterozygosity estimates. A lineage represented by one uniform population has
no within-lineage contrast, so its private-allele estimate is reported as
undefined rather than zero.

First rerun metadata validation so the edited `spID` values are copied into the
sample crosswalk:

```bash
Rscript scripts/01_validate_metadata.R \
  data/Dryas_sampledata_popgen.csv \
  data/s384_batchclean_ab25_locusFDR05_mac4_dp15-150_miss10.sorted.vcf.gz \
  results/metadata
```

Then run the lineage-aware calculations:

```bash
NBOOT=1000 bash scripts/12_run_refugia_statistics.sh
```

The principal outputs are
`results/refugia/uniform_population_refugia_metrics.tsv`, which retains each
geographic population, and
`results/refugia/uniform_lineage_diversity_summary.tsv`, which reports the
mean, median, and range across uniform populations in every lineage.

### 9. Polar phylogeographic map and population-genetic panels

The map reproduces the component alignment of the selected K16--K19 ADMIXTURE
solutions, ending with K19 replicate 10. The four selected Q matrices,
`sample_order.txt`, and the active-tree order used to initialize component
colors are stored in `data/admixture_K19/`. The supplied LGM spatial layer is
reprojected with the samples into Arctic Polar Stereographic coordinates
(EPSG:3995).

```bash
Rscript scripts/13_prepare_k19_map_data.R \
  data/admixture_K19 \
  data/Dryas_sampledata_popgen.csv \
  results/map

Rscript scripts/14_plot_phylogeography.R \
  results/map/aligned_K19_sample_map_data.tsv \
  results/map/aligned_K19_population_summary.tsv \
  data/LGM_boundary/LGM_boundary.shp \
  results/diversity \
  results/refugia/uniform_population_refugia_metrics.tsv \
  data/phylogeographic_regions.tsv \
  figures/14_dryas_phylogeography.pdf
```

The sample pies are deterministically offset within `geoID`, so repeated runs
have identical layouts. Pie outlines use the four diversity-signature colors
defined by population pi and private allelic richness; unselected samples are
gray. The 19 component names and high-contrast colors are editable in
`data/K19_component_labels.tsv`. Approximate hypothesis regions are controlled by
`data/phylogeographic_regions.tsv`; their radii are visual annotations rather
than inferred biological boundaries. The map follows the attached
`mapmixture` style using Natural Earth 1:50m country polygons, geographic
graticules, and a framed projected panel, while retaining an Arctic Polar
Stereographic projection. Useful plotting controls include
`MAP_JITTER_RADIUS_KM`, `MAP_PIE_RADIUS_KM`, `MAP_MIN_LATITUDE`,
`MAP_LAND_COLOR`, `MAP_SEA_COLOR`, `MAP_BORDER_COLOR`, `FIGURE_WIDTH`, and
`FIGURE_HEIGHT`.

The plotting step also writes
`results/map/population_refugial_signatures.tsv` and a standalone
`*_refugial_signatures.pdf` (4 x 5 inches). Drummondii is excluded from this
quadrant plot and from its default cutoffs because it is not equivalent to the
ingroup populations in the refugial comparison; it remains visible in the map
and side panels in gray. By default, medians across the remaining selected
populations divide high from low nucleotide diversity and private allelic
richness. These cutoffs can be replaced with `SIGNATURE_PI_CUTOFF` and
`SIGNATURE_PRIVATE_CUTOFF`. Points are unlabeled hollow circles whose outlines
show the assigned diversity signature.

## Statistical interpretation

- SNP heterozygosity is conditional on retained variable sites and is not
  genome-wide nucleotide diversity.
- Sequence-level nucleotide diversity will be calculated separately from the
  `.loci` file after confirming its identifier format and applying the batch-
  locus exclusions.
- Population definitions were informed by ADMIXTURE. Diversity and FST are
  therefore complementary descriptions, not independent proof of admixture.
- Strong secondary-contact evidence requires concordance among ancestry,
  elevated diversity relative to matched uniform populations, and affinity to
  more than one differentiated reference population.

The package choices follow the published *Pedicularis furbishiae* analysis,
with the additional one-SNP-per-ipyrad-locus step to respect linkage within GBS
loci.
